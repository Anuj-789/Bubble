# 🎮 3D Bubble Crusher Game

A fun and interactive **3D-style Bubble Crusher Game** built using pure HTML, CSS, and JavaScript.  
The game provides a smooth arcade experience where players control a glowing central circle and destroy incoming bubbles to increase their score.

🔗 **Live Demo:**  
https://anuj-789.github.io/Bubble/

---

## 📌 Project Overview

**3D Bubble Crusher** is a browser-based arcade game designed with modern UI effects and smooth animations.

The player controls the central glowing circle and tries to collide with colorful bubbles coming from different directions. Each successful collision increases the score, while missing bubbles results in a game over.

This project focuses on:
- Interactive gameplay
- DOM manipulation
- Collision detection
- Animation handling
- Responsive game design

## 🎮 How To Play

1. Open the game using the live demo link.
2. Move the glowing center circle using mouse or touch controls.
3. Collide with incoming bubbles to destroy them.
4. Every destroyed bubble increases your score.
5. Avoid missing bubbles because it will end the game.
6. Press **Replay** to start a new game.

---

## ⚙️ Game Mechanics

### Bubble Generation
- Bubbles are generated automatically from the top and bottom of the screen.
- Each bubble receives a random position and color.

### Collision System
The game continuously checks the distance between:
- Player controlled circle
- Moving bubbles

When collision occurs:
- Bubble disappears
- Score increases

### Difficulty System
- Bubble speed increases gradually after a fixed interval.
- The game becomes more challenging as time passes.
